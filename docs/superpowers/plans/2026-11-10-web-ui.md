# Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The browser app (build steps 3–8): load files in a worker, draw the graph with collapsible
subnet and Internet groups, a details panel, search and filters, settings, exports and sessions,
the "How to collect" page, and the opt-in DNS lookup.

**Architecture:** `index.html` is a Låda Glass shell with three views (Graph, How to collect,
Settings), routed by hash. `js/app.js` is a small controller that owns the state
`{files, settings, dns, positions, collapsed, dirty}`. It rebuilds the model with
`buildModel(files, settings)` and the Cytoscape elements with the pure `toElements(...)`. DOM
helpers render with `textContent` only. Parsing runs in a module Web Worker.

**Tech Stack:** Cytoscape.js 3.34.4 (MIT, released 2026-10-15), vendored as ESM in
`vendor/cytoscape-3.34.4/`. Låda Glass 1.1.1. No build step.

**Spec:** `docs/superpowers/specs/2026-11-10-netstat-parser-design.md` (UI, Settings, DNS lookup,
Data handling and exports, "How to collect" page). Consumes plans 1–2 (`parseFile`,
`decodeBytes`, `buildModel`, `applyFilter`, exports, session, dns).

## Global Constraints

- CSP: `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data: blob:;
  connect-src 'self' https://cloudflare-dns.com https://dns.google https://dns.quad9.net:5053;
  worker-src 'self'; object-src 'none'; base-uri 'none'; form-action 'self'`. No
  `unsafe-inline` / `unsafe-eval`.
- Cytoscape's injected `<style>` is pre-empted by
  `<link rel="stylesheet" id="__________cytoscape_stylesheet" href="css/cytoscape-container.css">`.
- Untrusted text (file content, session, DNS) goes into the DOM only via `textContent` /
  attributes, and into Cytoscape only as `data()` labels.
- Risk colours are CSS tokens on `:root` with light/dark variants: `--np-risk-vulnerable` (red),
  `--np-risk-exploitable` (orange), `--np-risk-safe` (neutral light grey in dark, mid grey in
  light), `--np-risk-unclassified` (dim blue-grey). Cytoscape reads them via `getComputedStyle`.
- Line style: solid = seen from both ends, dashed = one end. Seen-only hosts are greyed out
  (lower opacity, grey fill).
- Node shape by role: server = round-rectangle, client = ellipse, both = diamond, unknown =
  ellipse. A self-made OS icon is the node background image (an SVG data URI).
- Listening badges: up to 4 ports in a second label line (worst risk first), then `+N`. The node
  border colour is the worst listening risk. The full coloured badge list is in the panel.
- Groups start collapsed when hosts > `settings.graph.collapseThreshold`.
- No sideways scrolling at 375 px. Everything is keyboard reachable; the panel's Hosts and Files
  lists are the accessible alternative to the canvas.
- Settings (only) go to `localStorage` key `netstat-parser.settings.v1`, inside try/catch.

## Review Focus

1. **Loading the same file twice, or 1000 files at once.** Expect no duplicates (the same name and
   size replaces the old file) and a responsive page with progress → Task 3.
2. **A session saved with groups collapsed and nodes moved**, reopened after a settings change
   renames a subnet. Expect positions kept by ID, and the collapse state kept where group IDs still
   exist → Task 6.
3. **DNS lookup enabled, then cancelled halfway, then the tab closed.** Expect no further requests
   after Cancel, the partial names kept, and the unsaved-work warning → Task 8.
4. **Narrow screen (375 px).** Expect the panel to stack under the graph and the toolbar to wrap,
   with no horizontal scroll → Task 3 browser check.
5. **A file name or hostname containing HTML** (`<img src=x onerror=…>_netstat.txt`). Expect it
   shown as literal text everywhere → Task 3 test (elements) + browser check.

### Task 2: Pure Cytoscape elements

**Files:** Create `js/ui/elements.js`, `js/ui/icons.js`; Test `tests/elements.test.mjs`.

**Interfaces:** `toElements(model, {collapsed: Set<groupId>, visible: {hosts:Set, edges:Set}|null,
mode: 'fade'|'hide', dns: {ip:name}, labels: boolean}) -> {nodes: object[], edges: object[]}` in
Cytoscape JSON (`{data:{…}, classes:'…'}`). `osIcon(os) -> 'data:image/svg+xml,…'`.

- [ ] **Step 1: Failing tests** (generated `small` model):
  - With nothing collapsed: one parent node per group (`classes` includes `group` / `internet`),
    and every host node's `data.parent` is its group. Edge count = model edge count.
  - Collapsing `g:internet` replaces its hosts with one node `g:internet` whose `data.count`
    equals its host count. Edges to Internet hosts are merged per (source, collapsed group): the
    worst risk wins, `data.count` sums, and the result is `seen-one` if any part is one-sided.
  - Edges inside one collapsed group are dropped and counted in that node's `data.internal`.
  - A host classed `seen-only` iff `!collected`; `os-windows`, `role-server`; badges label
    `"DC01\n445 389 88 +3"` style (≤ 4 ports, worst risk first).
  - `mode:'fade'` keeps non-matching items with class `faded`; `mode:'hide'` omits them, and an
    edge is kept only if both endpoints are kept.
  - `dns` name shown as the label of an Internet host (IP stays in `data.ip`).
  - `<img src=x onerror=alert(1)>` as a hostname ends up only in `data.label` (as a string) and
    in no other field.
- [ ] **Step 2:** Run → FAIL. **Step 3:** Implement. **Step 4:** pass + lint. **Step 5:** Commit `feat(ui): model → Cytoscape elements`.
